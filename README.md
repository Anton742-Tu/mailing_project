# 📧 Система управления email рассылками

Профессиональная система для управления массовыми email рассылками, построенная на Django.

## 🚀 Возможности

### 📊 Управление рассылками
- ✅ Создание, редактирование, удаление рассылок
- ✅ Статусы: Создана, Запущена, Завершена  
- ✅ Периодичность: однократно/ежедневно/еженедельно/ежемесячно
- ✅ Ручная отправка через интерфейс и командную строку

### 👥 Управление клиентами
- ✅ Полный CRUD для клиентской базы
- ✅ Группировка клиентов для целевых рассылок
- ✅ Поиск и фильтрация клиентов

### 📨 Шаблоны сообщений
- ✅ Создание и управление шаблонами писем
- ✅ Валидация тем и содержимого сообщений
- ✅ Предпросмотр сообщений перед отправкой

- ✅ **Пользователи** - управляют только своими данными
- ✅ **Менеджеры** - просматривают все данные, блокируют пользователей
- ✅ Изоляция данных между пользователями
- ✅ Аутентификация и авторизация

### 📈 Аналитика и отчеты
- ✅ Детальное логирование каждой отправки
- ✅ Статистика успешных/неуспешных попыток
- ✅ Визуализация эффективности рассылок
- ✅ Отчеты по клиентам и рассылкам

### ⚡ Производительность
- ✅ Серверное кеширование данных
- ✅ Кеширование страниц и статистики
- ✅ Оптимизация производительности

## 🛠 Технологический стек

- **Backend:** Django 5.2.6, Python 3.12
- **Database:** PostgreSQL
- **Frontend:** Bootstrap 5, Bootstrap Icons
- **Cache:** Redis (опционально)
- **Email:** SMTP (Gmail, Yandex, etc.)

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <git@github.com:Anton742-Tu/mailing_project.git>
cd mailing_project
```
### 2. Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
### 3. Отредактируйте .env файл:

```bash
nano .env  # или используйте любой текстовый редактор
````
### 4. Заполните обязательные поля:
```
SECRET_KEY - сгенерируйте новый ключ
DB_PASSWORD - пароль для PostgreSQL
EMAIL_HOST_USER - ваш email
EMAIL_HOST_PASSWORD - пароль приложения
Генерация SECRET_KEY
```
### 5. Выполните команду для генерации нового секретного ключа:
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```
## Настройка PostgreSQL
### Установите PostgreSQL
1. Создайте базу данных и пользователя:
```sql
CREATE DATABASE mailing_db;
CREATE USER mailing_user WITH PASSWORD 'your-password';
GRANT ALL PRIVILEGES ON DATABASE mailing_db TO mailing_user;
```
2.  Запуск приложения
```bash
# Установка зависимостей
pip install -r requirements.txt
```
3. Миграции и суперпользователь
```bash
python manage.py migrate
python manage.py createsuperuser
```
4. Создание групп и тестовых данных
```bash
python manage.py create_groups
python manage.py create_test_users
```
5. Запуск сервера
```bash
python manage.py runserver
```
## Переменные окружения
### Обязательные:

### Скрипт для автоматической настройки
#### Создайте setup_env.py для помощи в настройке:
```python
#!/usr/bin/env python3
"""
Скрипт для настройки .env файла
"""

import os
from pathlib import Path
from django.core.management.utils import get_random_secret_key

def setup_env():
    env_file = Path('.env')
    
    if env_file.exists():
        print("⚠️  Файл .env уже существует!")
        response = input("Перезаписать? (y/n): ")
        if response.lower() != 'y':
            print("Отменено.")
            return
    
    # Генерация секретного ключа
    secret_key = get_random_secret_key()
    
    # Шаблон .env
    env_template = f"""DEBUG=True
SECRET_KEY={secret_key}
ALLOWED_HOSTS=localhost,127.0.0.1

DB_NAME=mailing_db
DB_USER=mailing_user
DB_PASSWORD=введите-пароль-бд
DB_HOST=localhost
DB_PORT=5432

EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_HOST_USER=ваш-email@gmail.com
EMAIL_HOST_PASSWORD=пароль-приложения
"""
    
    with open('.env', 'w', encoding='utf-8') as f:
        f.write(env_template)
    
    print("✅ Файл .env создан!")
    print("📝 Не забудьте отредактировать пароли в файле .env")

if __name__ == "__main__":
    setup_env()
```
### Запустите скрипт:

```bash
python setup_env.py
```
